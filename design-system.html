01

BRAND & IDENTITY

品牌

MYRQVIA 的标记是一枚四角火花，来自“新星”的最简形状：没有描边、没有光晕， 只保留四个向内收拢的尖角。它必须永远以单色出现，并与字标保持固定的呼吸。

品牌标本

MARK / WORDMARK
四角火花 · 单色
MYRQVIA CHAT 2.0

字标字距 .22em，全大写，不替换为其他字体。

比例火花高度 = 字标大写高度，间距 8px。

态度不旋转、不描边、不加阴影或发光。

用法 应用内头部为 16px 火花 + 12.5px 字标 + 9px 版本号；此标本仅用于放大检查，不按此尺寸上线。

净空区

CLEAR SPACE
0.5X 0.5X

规则 四周净空 = 火花高度 X 的 0.5 倍，且不小于 8px。净空区内不得出现文字、图标、描边或图片边缘。

禁止

OFF-LIMITS
  • ×
    紫色 / 蓝紫渐变

    不建立第二强调色；禁止以 #7C5CFF 一类色相主导界面。

  • ×
    整页玻璃与透明堆叠

    液态玻璃只用于导航、菜单和浮层；正文、设置与长列表保持实底，不做整页磨砂。

  • ×
    发光与彩色投影

    阴影只用于表达真实层级，不做光晕。

  • ×
    饱和度堆叠

    同一屏不允许出现三种以上高饱和色块。

  • ×
    任意装饰色

    渐变描边、彩色图标底、彩色标签均不成立。

判断 如果一个颜色不能回答“它表达什么状态”，它就不应该出现。

03

TYPOGRAPHY

字体

字体不表演。它只负责让中文、拉丁字母与数字在同一行里保持相同的呼吸。 系统字体栈优先使用平台原生的 SF Pro 与 Segoe UI Variable，中文回落到 Noto Sans SC / PingFang SC。

字体栈

SYSTEM FONTS ONLY
--font-ui -apple-system, BlinkMacSystemFont,
"SF Pro Text", "SF Pro Display",
"Segoe UI Variable Text", "Segoe UI",
"Noto Sans SC", "PingFang SC",
"Microsoft YaHei UI", sans-serif
  • AppleSF Pro Text 用于 ≤ 19px，SF Pro Display 用于更大的标题；不引入 Web Font。
  • WindowsSegoe UI Variable Text 优先，Segoe UI 回落；中文字重 400 / 500 / 600 / 700。
  • 中文Noto Sans SC → PingFang SC → Microsoft YaHei UI；不合成斜体、不伪造粗体。
  • 数字时间、版本、大小与计数使用 tabular-nums，避免跳动。

规则 界面只用系统字体。字距是排版参数，不是装饰：大标题收紧，微文案放开；中文正文保持 0 附近。

MOTION

动效

动效只做三件事：解释东西从哪里来、确认一次操作、帮助一段内容退场。 所有曲线都短、可控，并且可以被系统级“减少动态效果”一键降级。

RECALL DISSOLVE · 1.74S

撤回不是一次系统删除，而是一句话安静地退场。气泡从右上角开始，被切分为 3–4px 的像素格， 沿对角线分三波向左下漂移、旋转、缩小并淡出。方向与阅读方向相反，结尾比开头慢。

PRINCIPLES & DON'TS

原则

设计系统不是更多规则，而是更少例外。下面八条约束用于判断一个新界面是否还属于 MYRQVIA， 最后一份清单用于快速排除那些“看起来更高级、实际更吵”的做法。

  1. 01

    克制

    先删除，再添加。一个屏幕只保留一个视觉焦点，装饰不解决问题就不出现。

  2. 02

    层级

    用字号、字重、留白和发丝线建立顺序；不靠阴影、彩色块或大面积背景。

  3. 03

    一枚蓝色

    强调色只用于可操作与未读。绿色、红色、橙色只表达状态，不参与品牌表达。

  4. 04

    原生动效

    动效要解释空间关系。时长短、方向明确、可被系统降级，永远不阻塞输入。

  5. 05

    像素纪律

    4 / 8 网格、统一圆角、1px 发丝线。看起来“差不多”的值，最后都会变成不一致。

  6. 06

    诚实的交互

    能做的就做，不能做的直接说明。不用 toast 假装功能存在，不用假数据伪装在线。

  7. 07

    明暗对等

    深色不是反色。两套主题共享语义与层级，深色单独校准对比、阴影与头像色。

  8. 08

    性能预算

    动效只用 transform 与 opacity；图片按容器裁切；本地原型不引入外部字体与脚本。

NOT MYRQVIA

这些做法不属于 MYRQVIA

  • ×紫色 / 蓝紫渐变作为主视觉
  • ×整页玻璃拟态、透明卡片堆叠
  • ×发光、彩色投影、霓虹描边
  • ×装饰性图标与无意义的插画
  • ×层层嵌套的圆角卡片
  • ×用持续动画掩盖加载与等待

如果去掉一个效果之后信息更清楚，那这个效果就不应该存在。

让内容成为主角，让界面退后半步。
